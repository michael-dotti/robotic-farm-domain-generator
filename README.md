# robotic-farm-domain-generator
Questo codice è un esempio di utilizzo di l2p per generare il file domain pddl a partire da una testo scritto in linguaggio naturale.

Il codice ti da la scelta di utilizzare due LLM:
- qwen2.5-coder:7b -> open sourse da scaricare in locale tramite Ollama
- gemini -> AI che non richiede di utilizzare le risorse del tuo pc
